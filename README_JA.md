<h1 align="center">9monsters Privacy</h1>

<p align="center">現在のアカウントですでに閲覧できるプライベートアルバムを自動で収集し、Loon 内にローカルアルバムページを生成します。</p>

## 機能

- アルバムのグループ名、画像 ID、収集日時を自動で記録します。
- 画像 ID ごとに重複を除外するため、同じ内容を再度閲覧しても同一画像は追加されません。
- グループ別の画像表示、グループ名検索、遅延読み込み、画像プレビュー、元画像を開く機能に対応しています。
- 新しい画像が見つかったときに Loon の通知を送信できます。
- `http://album.loon.invalid/` からローカルアルバムを開けます。

> [!IMPORTANT]
> 本プラグインは、現在のアカウントに閲覧権限があり、9monsters 上で通常どおり開けるアルバムのローカルインデックスを作成するものです。クラッキング、ロック解除、アクセス制限の回避機能はありません。

## 動作要件

- iOS のみ
- システム設定で Loon の通知が許可されていること
- Loon 3.5.1 (983) 以降
- Loon で Script、Rewrite、MitM が有効になっていること
- Loon の MitM 証明書が端末にインストールされ、信頼済みであること

## インストール

### ワンタップでインポート

[**ワンタップでインポート**](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Ffafatop%2F9monsters-privacy%2Fmain%2Fmain.plugin)

Loon が自動で開かない場合は、以下の URL を手動で追加してください。

### 手動インストール

Loon の Plugins 管理画面で、次の URL を追加します。

```text
https://raw.githubusercontent.com/fafatop/9monsters-privacy/main/main.plugin
```

プラグインを有効にし、`api.ninemonsters.com` の HTTPS 復号が正常に動作することを確認してください。

## 使用方法

1. Loon と本プラグインを有効にしておきます。
2. 9monsters を開き、現在のアカウントでプライベートアルバムを閲覧できるユーザーのプロフィールへ直接移動します。通知が表示され、画像一覧の読み込みが完了するまで少し待ちます。
3. ブラウザで `http://album.loon.invalid/` を開きます。
4. ページの `刷新`（更新）を選択すると、最新のグループと画像を確認できます。

プラグイン設定の `新增图片通知`（新しい画像の通知）は初期状態で有効です。Loon のプラグイン設定から無効にできます。

## データとプライバシー

本プラグインが Loon の `$persistentStore` に保存する情報は、次の項目だけです。

- アルバムのグループ名。
- 画像ファイル ID。
- グループの作成・更新日時と画像の収集日時。

元の画像ファイルは `$persistentStore` に保存されません。また、API リクエストの `public_key` も保存しません。ローカルアルバムで画像を表示するときは、ブラウザが元の CDN URL から画像を読み込みます。

「Loon のローカルアルバムに保存」とは、Loon 内にアルバムのインデックスを保存し、閲覧用ページを生成することを意味します。iOS の写真アプリに画像を保存する機能ではありません。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| `main.plugin` | Loon プラグインのエントリーポイントとルール設定 |
| `collect.js` | グループ名、画像 ID、日時情報を収集 |
| `gallery.js` | Loon のローカルアルバムページを生成 |
| `icon.png` | プラグインアイコン |

## バージョン規則

現在のバージョン：`v1.1`

今後の正式リリースでは、`v1.2`、`v1.3`、`v1.4` のように連番で更新します。プラグイン名に含まれるバージョン番号は公開リリースを示します。スクリプトとアイコンの URL 末尾にあるクエリパラメータには現在のリリース番号を使用し、キャッシュを更新します。
